# Подготовка к аудиту безопасности компании PropDevelopment

## Планы и проблемы компании

### Проблемы
- Специалисту по ИБ передают не все решения и изменения.
- Нарушен контроль данных:
    - Есть несколько точек регистрации нового клиента, координации между этими точками нет.
    - Внутренние потоки данных между IT-продуктами контролируются не системно.
    - Ограничения по передаваемым данным в основном обусловлены бизнес-процессами между взаимодействующими IT-продуктами.
    - Со стороны систем обработки данных нет ограничений на доступ к данным.
- Проблемы с API партнёров:
    - Нет единых политик по безопасности: в контрактах API фигурируют персональные данные.
    - Нет системного контроля за передаваемыми данными: контракты API разрешают передачи данных, противоречащие законодательству.
- Не достаточный уровень уровень удовлетворенности клиентов: они видят в приложении ошибки, когда заходят в личный кабинет.
- Компания не может расширять направление обработки данных: проблема управления и хранения потоков данных блокирует реализацию.
- Потенциальная неготовность к инцидентам и рыночным изменениям: у конкурента произошла утечка данных, которая активно обсуждалась в СМИ, руководство хочет предотвратить подобные сценарии.

### Планы
- Компания планирует активно развивать клиентские сервисы для покупателей и жильцов в том числе за счет интеграций с партнерами.
- Повысить уровень удовлетворённости клиентов за счет выявления и устранения ошибок.
- Подготовка к возможным атакам с целью предотвращение инцидентов (например утечек).
- Повышение готовности реагировать на инциденты и изменения на рынке.
- Проверить соответствие требованиям законодательства:
    - новые интеграции с поставщиками услуг;
    - текущие бизнес-процессы компании.

## Выбор разделов проверочного листа

Включены в проверочный лист:
- Управление доступом - критически важно:
    - есть атаки на похожие компании,
    - у PropDevelopment нарушен контроль данных.
- Безопасность данных - критически важно:
    - у компании есть сомнения в соблюдении законодательства в работе с данными,
    - необходимо развивать сервисы работы сданными (AI, ML, BI) .
- Защита инфраструктуры - важно:
    - есть атаки на похожие компании,
    - базовые меры по защите уже приняты (firewall, копирование данных).
- Управление инцидентами - важно:
    - есть атаки на похожие компании,
    - нарушена коммуникация между командами и сотрудником ИБ.

Не включены в проверочный лист:
- Специфические вопросы - не входят в список текущих целей компании, ресурсов на их реализацию не хватит так как специалист по ИБ всего один.
