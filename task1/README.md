#  Проверочный лист безопасности данных компании PropDevelopment

Анализ представлен в виде mind-map ([drawio](./sec-data-mind-map.drawio) | [png](./sec-data-mind-map.png)). Кроме того в следующих разделах документа приведено табличное описание данных компании так как это оказалось удобным при составлении mind-map.

Использованные сокращения:
- ПД - персональные данные.
- РД - регистрационные данные (логин, пароль и тд).
- НК - некачественные (данные).
- НЗ - незначительный.

Некоторые виды данных на mind-map сгруппированы для увеличения читабельности (например РД: РД клиентов, РД собственников, РД менеджеров и тд).

## Оценка рисков при работе с данными в PropDevelopment

В комментариях использован термин ошибки. Он является обобщением для искажений (намеренная порча) и НК данных (неумышленные дефекты).
